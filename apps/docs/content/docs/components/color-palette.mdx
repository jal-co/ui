## Usage

```tsx
import { ColorPalette } from "@/components/color-palette"
```

```tsx
<ColorPalette colors={[{ name: "Primary", value: "#6366f1" }]} />
```

Client component. Click any swatch to copy its color value to the clipboard. Supports hex, rgb(), hsl(), oklch(), and named CSS colors.

## Notes

- **Click to copy.** Click any swatch to copy its color value to the clipboard.
- **Adaptive contrast.** Copy icons switch between light and dark based on the swatch background.
- **Any CSS color.** Supports hex, rgb(), hsl(), oklch(), and named CSS colors.
- **Icon library.** Uses [Lucide](https://lucide.dev) icons by default.

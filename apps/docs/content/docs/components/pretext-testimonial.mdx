## Notes

- **Pretext-powered.** Uses [@chenglou/pretext](https://github.com/chenglou/pretext) for pure-arithmetic height prediction.
- **Wraps TestimonialCard.** Uses the same card component from the `testimonial` registry item — consistent styling.
- **Zero layout shift.** Cards are absolutely positioned using predicted heights. No reflow, no CLS.
- **Font matching.** The `font` and `lineHeight` props must match the CSS styling of the quote text inside TestimonialCard.

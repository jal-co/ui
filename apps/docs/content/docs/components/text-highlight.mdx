## Notes

- **Pretext-powered.** Uses [@chenglou/pretext](https://github.com/chenglou/pretext) for pure-arithmetic text measurement.
- **Line-aware highlights.** Ranges that span multiple lines render separate highlight backgrounds per line — no clipping or overflow issues.
- **Font matching.** The `font` and `lineHeight` props must match the CSS styling of the rendered text for accurate positioning.

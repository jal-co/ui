## Notes

- **Inline marks.** Uses native `<mark>` elements — highlights wrap correctly across line breaks with no JS measurement needed.
- **Server-compatible.** No client-only dependencies. Works in RSC and SSR.
- **Labels.** Optional badge labels are positioned absolutely above the first character of the highlighted range.

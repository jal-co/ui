
```tsx

```

Async server component — fetches data at build time with ISR caching.

## Notes

- **Async server component.** No client JS required.
- **ISR caching.** Data is cached for 1 hour via `next.revalidate`.
- See the [source code](https://github.com/jal-co/ui) for the full API.

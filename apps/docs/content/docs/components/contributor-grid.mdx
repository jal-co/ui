## Usage

```tsx
import { ContributorGrid, ContributorList } from "@/components/contributor-grid"
```

```tsx
<ContributorGrid owner="vercel" repo="next.js" />
```

Async server component — fetches contributors from the GitHub API at build time. Cached for 1 hour via ISR. Optional `GITHUB_TOKEN` raises the rate limit.

## Notes

- **Async server component.** No client JS for the grid. List layout uses Radix Tooltip.
- **ISR caching.** Contributor data cached for 1 hour. No API key required.
- **Pre-fetched data.** Pass the `contributors` prop to skip the API call.

## Notes

- **Pretext-powered.** Uses [@chenglou/pretext](https://github.com/chenglou/pretext) for pure-arithmetic text measurement.
- **Better than CSS `text-wrap: balance`.** CSS balance only works up to ~6 lines, is inconsistent cross-browser, and can't be controlled. This works on any length and is deterministic.
- **Font matching.** The `font` prop must match the CSS font shorthand of the rendered text. Include weight and size (e.g. `'700 24px Inter'`).

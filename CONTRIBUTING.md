# Contributing

Thanks for your interest in contributing to jalco ui.

## Setup

```bash
git clone https://github.com/jal-co/ui.git
cd ui
pnpm install
pnpm dev
```

## Commits

This project uses [Conventional Commits](https://www.conventionalcommits.org).

```
feat(registry): add new component
fix(docs): correct install command
refactor(ui): simplify code block
```

## Pull requests

- Keep changes focused and easy to review
- Update docs when behavior changes
- Include screenshots for UI changes
- Explain what changed and why

## Code style

- TypeScript, Tailwind CSS, React server components where possible
- Prefer small, composable components
- Accessible by default
- No unnecessary dependencies

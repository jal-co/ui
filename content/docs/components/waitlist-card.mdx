## Installation

```bash
npx shadcn@latest add https://ui.justinlevine.me/r/waitlist-card.json
```

## Usage

```tsx
import { WaitlistCard } from "@/components/waitlist-card"

export function MyPage() {
  return <WaitlistCard />
}
```

The component handles its own form state internally. In a real project, you'd replace the `handleSubmit` function with your API call.

## Features

- **Email validation** — uses native HTML `required` + `type="email"` validation.
- **Accessible** — proper label, `aria-live` for the status region, keyboard navigable.
- **Responsive** — stacks vertically on mobile, inline on larger screens.
- **Feedback state** — shows a success message with the submitted email after form submission.
- **Backdrop blur** — subtle glassmorphism effect on supporting browsers.

## Customization

The card is a standard React component using shadcn's `Card`, `Input`, and `Button` primitives. Common modifications:

- **Connect to an API** — replace the `handleSubmit` function with a call to your email service (Resend, ConvertKit, etc.)
- **Add loading state** — add a pending state during the API call
- **Customize copy** — update the title, description, and status messages
- **Adjust width** — change `max-w-xl` on the root `Card`

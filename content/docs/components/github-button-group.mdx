## Installation

The button group is included in the `github-stars-button` component package:

```bash
npx shadcn@latest add https://ui.justinlevine.me/r/github-stars-button.json
```

## Usage

```tsx
import { GitHubButtonGroup } from "@/components/github-button-group"

export function MyComponent() {
  return <GitHubButtonGroup owner="shadcn-ui" repo="ui" />
}
```

This is an **async server component** — it fetches all repo metrics in a single GitHub API call at build time, cached for 1 hour.

## API Reference

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `owner` | `string` | — | GitHub username or organization. Required. |
| `repo` | `string` | — | GitHub repository name. Required. |
| `metrics` | `("stars" \| "forks" \| "watchers" \| "issues")[]` | `["stars", "forks", "watchers"]` | Which metrics to display, in order. |
| `variant` | `"default" \| "outline" \| "ghost" \| "subtle"` | `"default"` | Visual style variant. |
| `size` | `"sm" \| "default" \| "lg"` | `"default"` | Button group size. |
| `showRepo` | `boolean` | `false` | Show the `owner/repo` label as a leading segment. |
| `iconStyle` | `"currentColor" \| "github" \| "copilot" \| "muted"` | `"currentColor"` | Octocat icon color (visible when `showRepo` is true). |

## Notes

- Each metric segment links to the corresponding GitHub page (stargazers, forks, watchers, or issues).
- Returns `null` if the GitHub API call fails — handle this with a Suspense boundary or fallback if needed.

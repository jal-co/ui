## Installation

```bash
npx shadcn@latest add https://ui.justinlevine.me/r/github-stars-button.json
```

## Usage

```tsx
import { GitHubStarsButton } from "@/components/github-stars-button"

export function MyComponent() {
  return <GitHubStarsButton owner="shadcn-ui" repo="ui" />
}
```

Since this is an **async server component**, it must be rendered in a server context. It fetches the GitHub API at build time and caches the result for 1 hour via Next.js ISR.

## API Reference

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `owner` | `string` | — | GitHub username or organization. Required. |
| `repo` | `string` | — | GitHub repository name. Required. |
| `variant` | `"default" \| "outline" \| "ghost" \| "subtle"` | `"default"` | Visual style variant. |
| `size` | `"sm" \| "default" \| "lg"` | `"default"` | Button size. |
| `stars` | `number` | — | Pre-fetched star count. Skips the API call when provided. |
| `showRepo` | `boolean` | `false` | Show the `owner/repo` label alongside the count. |
| `iconStyle` | `"currentColor" \| "github" \| "copilot" \| "muted"` | `"currentColor"` | Octocat icon color style. |

## Notes

- **No API key required.** The component uses the public GitHub REST API. Optionally set `GITHUB_TOKEN` as an environment variable to raise the rate limit from 60 to 5,000 requests/hour.
- **ISR caching.** Results are cached for 1 hour via `next.revalidate`.
- **Pre-fetched stars.** Pass the `stars` prop to skip the API call entirely — useful when you already have the data.
